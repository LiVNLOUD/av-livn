# Mapillary aydınlatma incelemesi (I3)

I3: Mapillary küçük resimlerinin gözle incelemesi (Claude, 2026-11-03). Ayrımlar: direk görünüyor / ışık suya yönelik / ilgili saatte çalışıyor. Gündüz fotoğrafından çalışma durumu ya da lux üretilmez; görüntü yokluğu 'aydınlatma yok' değildir. OSM street_lamp ile seyir feneri (seamark:light) ayrı tutulur; fener puanı artırmaz.
